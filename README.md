# MD SIAM - WordPress & Automation Portfolio

Professional portfolio website for MD SIAM, a WordPress Expert and Automation Specialist.

## Tech Stack

- **React** (Vite)
- **Tailwind CSS**
- **Lucide React** (Icons)

## Features

- **Modern UI/UX**: Clean, dark-mode design.
- **Dynamic Portfolio**: Filterable project gallery.
- **Professional CV Generator**: Integrated ATS-friendly resume preview and download.
- **Responsive Design**: Optimized for all devices.

## Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run development server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```

## Deployment

The project is ready for deployment on platforms like Netlify, Vercel, or GitHub Pages.
